# Esl_Reports Generator
link to deployed app: https://esl-reports.onrender.com/

This is a lightweight web application for generating PDF reports of student progress. Teachers can fill in student information, select coursework, and export a styled report in one click.

## Features

- Select student and course details
- Add learning objectives, progress, and areas of improvement
- Export a professional PDF report
- Simple and fast interface using Flask and FPDF

## Technologies Used

- Python
- Flask (Web Framework)
- FPDF (PDF Generation)
- HTML / CSS (for templates)
- Deployed free on https://esl-reports.onrender.com/)

## Installation
